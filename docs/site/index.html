SLIME LAUNCHER
Docs GitHub

Controller-first launcher frontend for Prism Launcher

Slime Launcher is a native C++20/Qt 6 frontend wrapper for Prism Launcher on Arch Linux. It renders your instance library as a console-style poster grid and executes every launch through Prism's own CLI — no sandbox, no middleware.

GitHub Repo Build Guide Docs

Key features

01 Native C++20 / Qt 6 Widgets

No QML, no web views, no runtime interpreters. One binary, Qt 6.2+ and a C++20 compiler are the only dependencies.

02 Zero-sandbox CLI execution

Launches route directly through prismlauncher --launch <id> via detached processes. Flatpak Prism is detected and rejected — native packages only.

03 Gamepad spatial navigation

Reads /dev/input/js* directly — no SDL2. D-pad and analog stick drive the same focus model as keyboard and mouse, with hold-repeat and hot-plug support.

04 Automatic slimelauncher/ asset parsing

Every Prism instance gets an asset folder: 2:3 poster art, deterministic default seeding, and a center-crop engine (300×450–600×900) for custom covers.
